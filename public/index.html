FAQ

Useful answers before you download

Is the first generation free?

Yes. The app includes a free first generation so you can try the workflow before subscribing.

Does it only write easy cards?

No. Prosepal is especially useful for harder moments like sympathy, apology, encouragement, get well, and awkward professional notes.

Will the message sound generic?

The app uses your selected occasion, relationship, tone, length, and optional details to make the drafts more specific. You should still edit the final wording before sending.
